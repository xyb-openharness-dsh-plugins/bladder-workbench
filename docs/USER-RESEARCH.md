## 1 为什么膀胱癌要同时服务两条线（根子上的差异）

膀胱尿路上皮癌按是否侵犯肌层分为 NMIBC（非肌层浸润）与 MIBC（肌层浸润），**这是两种目标完全不同的处境**（E1，2022 保膀胱共识）：

- **NMIBC 线**：目标是**保住膀胱**，节奏是 TURBT + 膀胱灌注 + 长期膀胱镜复查。
- **MIBC 线**：目标是**活下来并学会带着改道生活**，主干是根治性膀胱切除 + 尿流改道，或三联保膀胱。

分野直接回答「**我还有没有膀胱**」。所以首屏必须先问一次分野（`DESIGN-08`），不能默认一种病人。

**三条并列的记录主体**（`DESIGN-09`）：
- **A · NMIBC 患者本人**（多为中老年，记录精力有限）
- **B · MIBC 患者本人**（术后身体负担重，短期高强度记录）
- **C · 照护者**（配偶/子女，**实际的主要录入者**，不是配角）

## 3 ⚠️ 五条做错了会伤人的假设（必须在 G1 由用户裁定）

1. **「记录复发恐惧」可能反而加重焦虑**（A8）。缓解不了就撤掉，或改为**非每日**的轻入口。
2. **「保膀胱」不得被写成默认正确选项**（A7）。工作台对"保还是切"**零倾向表达**——包括配色、排序、措辞、默认值。
3. **「未见肌层」不得被渲染成好消息**（B3）。它是"分期可能不完整"，不是"病很轻"。
4. **「非典型细胞」不得二分**（A6）。四态必须都能表示，且都不给倾向色。
5. **照护者不是配角**（C 线）。录入动线按主要录入者设计，患者端可只读。

## 4 如果以后有访谈机会，要问的问题（现在没有）

按"发现任务"而不是"确认功能"来问：

1. 上一次复查前一周，你最担心的是什么？有没有为它做过什么？
2. 上一次去做灌注，你怎么知道这次是第几次、下周还要不要来？
3. 有没有哪一次到了医院却没做成？当时听懂为什么了吗？
4. 如果现在让你给医生写三个问题，你会写什么？
5. （B 线）术前谈三种改道时，你记住了几句？回家后问了谁？
6. （C 线）你接手记录时，第一件搞不清的事是什么？
7. 你有没有一个"翻不到"的东西——照片、单子、医生说的话？

**问题设计原则**：问**最近一次的真实动作**，不问"你希望有什么功能"。
