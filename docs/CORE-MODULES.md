# 四个核心模块 · 小泉宝 UroPal

> 目的：把「这个工作台为什么不是换个癌种名」压到四条可验收的模块上。
> 依据：`docs/DIFF-MATRIX.md`（15 行差异化矩阵）、`docs/SCENARIOS.md`（S01–S16）、`docs/USER-RESEARCH.md`。
> 状态：**本文件是 phase1 交付物，未经 G1/G2/G3 任何一道闸口签认。**

## 判定标准

一个模块算「核心」，必须同时满足：

1. **离开膀胱癌就不成立**（换成淋巴瘤/乳腺癌/卵巢癌/肺癌都不成立或无意义）；
2. **患者自己会反复用到**，不是医生流程的搬运；
3. **有一个具体的失败后果**——做错了会让患者误解或做错决定。

按这三条从 `docs/SPEC.md` 的 M01–M14 里筛出四个。其余十个模块（M01 分野、M04 手术、M07 肾功、M08 急症、M09 私密、M10 代记、M11 复诊、M12 试验、M13/M14 指标）都是必要构件，但**不满足第 1 条或第 3 条**，故列在文末「支撑模块」。

## 核心一 · M02 病理核对（把报告翻译成人话）

**离开膀胱癌为什么成立不了**
膀胱癌的病理报告有一个**特有的歧义陷阱**：报告写「浸润固有层（T1），**未见肌层组织**」。
「未见肌层」在中文语感里像好消息（"没看到肌肉，那应该没浸润吧"），实际含义恰恰相反——**这次取材没取到肌肉层，所以无法判断 T1 还是 T2，分期是不完整的**。
`docs/USER-RESEARCH.md` 把这条列为误解风险第 1 位。

**用户任务** 把一份看不懂的病理结论，变成「我知道自己属于哪条线、我下次要问什么」。

**规则要点**（`docs/SPEC.md` M02）
- `grade_raw` / `grade_scheme_raw` **两套分级并列保存原文，不做任何映射、不出现等价表述**。依据：已精读的 11 份中文共识里 `G1/G2/G3` **零出现**，只有「低级别/高级别」。所以工作台**不写**「G2 ≈ 高级别」。
- `muscle_present = 无` → 必须渲染成「分期可能不完整，是需要问医生的点」，**不得渲染成好消息**。
- 报告未提及 = `未提及`，**不等于**「无」。
- 认不出的词照录 + 标「未核实」。

**验收** AC-05 至 AC-08。原型已实现 AC-05（`prototypes/v0.1/app.js` 分野与分型页的「未见肌层」警示）。

**未核实** 2021 灌注共识表 1、2024 保膀胱共识表 5/表 6 是**图片**，危险度分组的文字判据**未取得**，原型里因此**不做任何分层判断**，只留位置并标「来源待补」。

## 核心二 · M03 膀胱灌注（最独有）

**离开膀胱癌为什么成立不了**
膀胱灌注是膀胱癌独有的给药途径——把药打进膀胱里泡着。淋巴瘤/乳腺癌/卵巢癌/肺癌**都没有**这条线。它同时是 NMIBC 患者最主要的长期治疗负担：长期要按周期排程、每次要憋尿、有禁忌、有副作用。

**用户任务** 知道「我这轮到第几次了、下一次什么时候、这次为什么被取消」。

**规则要点**（`docs/SPEC.md` M03，E1 依据 2021 灌注共识）
- 计划结构：**即刻 24h 内**；**诱导每周 1 次 × 6～8 次**；**维持每 2～4 周 1 次**。BCG 诱导须**术后 ≥2 周**。
- 国产 BCG 每次 **120 mg**、1 年共 **19 次**；SWOG 方案 3 年共 **27 次**。
- **化疗灌注禁忌 4 条**：膀胱穿孔 / 肉眼血尿 / 严重化学性膀胱炎 / 急性尿路感染；**BCG 另加 2 条**：术后 2 周内 / 创伤性导尿。
- **取消必须解释为「这是禁忌保护」，不是出事了。** 这条是产品判断：患者看到「取消」第一反应是病情恶化。
- **漏一次不给任何处置建议**（原文无统一口径）。
- `retention_minutes`（憋尿时长）原文是图片未获取 → 字段存在但默认空，标「来源待补」，**不得给建议值**。

**验收** AC-09 至 AC-12。原型已实现：周期两段结构、取消原因以「保护」解释、BCG 与化疗药物集不同。

**本模块最要紧的一条**：**不给建议**。灌注节奏是医生决定的，工作台只记录与解释。

## 核心三 · M05 尿流改道与造口（不可逆事实 + 批量录入）

**离开膀胱癌为什么成立不了**
膀胱癌是少数会**整个拿掉一个器官**的癌种，而且拿掉之后**必须换一种方式排尿**。三种术式的日常生活**完全不同**：

| 术式 | 排尿方式 | 患者每天面对的 |
|---|---|---|
| 回肠通道（Bricker） | 腹壁造口 + 集尿袋 | 底盘型号、更换周期、渗漏、皮肤并发症 |
| 原位新膀胱 | 靠自己尿道 | 控尿训练、间歇导尿、夜间漏尿 |
| 输尿管皮肤造口 | 腹壁两个小口 + 支架 | 支架管护理、吻合口 |

问卷与共识都指出患者最怕的是**造口相关**（CACA 48 条患者问答里，造口与尿流改道占约 19 条，是最大一类）。

**用户任务** 术式选定后，能按照护者视角**一次录一批**（底盘更换、渗漏、皮肤状态），而不是每天 1–2 分钟随手记——后者会把多字段模块压扁。

**规则要点**（`docs/SPEC.md` M05，DESIGN-09）
- 术式是**不可逆事实**：改动**留痕不覆盖旧值**。
- 三种术式**各自独立页签**，不合并成一张卡（合并会让三套日常互相污染）。
- 按**照护者批量录入**设计；患者端只做只读 + 打勾 + 急症。

**验收** AC-16 至 AC-19。原型已实现三术式对照 + 造口日记批量录入界面。

**未核实** 回肠切除后的 **B12 缺乏 / 代谢性酸中毒**长期负担：**11 份中文共识中未涉及**，字段保留、判断不做。

## 核心四 · M06 复查与膀胱镜（长期复查 + 恐惧管理）

**离开膀胱癌为什么成立不了**
NMIBC 的复查是**长期的**（2022 版保膀胱共识只写「长期密切随访」，未设上限；全站禁用「终身」），高危**每 3 个月一次膀胱镜**。膀胱镜是**有创检查**，且患者普遍在检查前焦虑。同时膀胱癌有一个家族里唯一的长期监测需求：**上尿路（肾盂/输尿管）是第二原发监测部位**（依据 HER2 共识：我国尿路上皮癌 20%～30% 来自肾盂及输尿管）——治好了膀胱，还得盯着另外两个器官。

**用户任务** 知道「下次镜检是什么时候、上次结果是什么、有没有盯上尿路」。

**规则要点**（`docs/SPEC.md` M06）
- 复查节奏：**术后 2 年内每 3 个月**（B 超 + 胸片 + 膀胱镜）；**2～5 年每 6 个月**；**5 年后每年**（CACA 患者问答原文）。
- 尿细胞学**四态**（阴性 / 非典型 / 可疑 / 阳性），且**自然尿与膀胱冲洗标本要分开记**——两者判读口径不同。
- 上尿路监测作为**第二原发部位**长期跟踪（输尿管吻合口复发、对侧上尿路）。
- 膀胱镜记录：柔性/硬性、是否麻醉、疼痛评分。**不写「正常」**，只写报告原文。

**验收** AC-20 至 AC-23。原型已实现尿细胞学四态 + 上尿路监测页。

**未核实** 膀胱镜随访的**终止条件**：中文共识未给，工作台**不写「可以停了」**。

## 支撑模块（必要，但不满足「核心」三条）

| 模块 | 为什么不算核心 |
|---|---|
| M01 分野 | 是**入口闸门**而非独立任务；它决定后四个模块显示什么，本身不产生记录 |
| M04 手术与 TURBT | 与 M05 高度耦合，单独看接近通用「手术事件」模型 |
| M07 肾功能与顺铂门槛 | 与肾癌共享，不是膀胱癌独有（但**决定治疗分叉**，故在 SPEC 中给足字段） |
| M08 急症与安全 | 结构通用（判据 + 联系入口），内容换癌种即换；价值高但不算差异化 |
| M09 私密 / M10 代记 / M11 复诊 / M12 试验 | 家族通用能力，各癌种都要有 |
| M13 指标目录与一图秀 / M14 指标分级与提醒 | 脚手架级能力，按 `docs/16`/`docs/23`/`docs/24` 落地 |

## 这四个模块共同的产品立场

1. **不换算、不判断、不给建议**——工作台保存原文、解释原文、把问题交回给医生。
2. **分野不清则一切不清**——所以 M01 闸门在前，四个核心模块在后。
3. **不可逆的事必须留痕**——改道术式改动不覆盖旧值。
4. **能被照护者接手**——批量录入 > 只能患者自记。
