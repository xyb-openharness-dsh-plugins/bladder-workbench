# SCENARIOS · 小泉宝 UroPal · 膀胱癌

> **依据**：`prompts/NEW-CANCER-WORKBENCH.md §5`——场景细化是**核心交付**，追踪链必须闭合：
> `证据 E → 需求 N → 场景 S → 功能 F → 数据/交互 → 验收 A`
> **写法**：每条场景只写三要素——**触发**（决定入口在哪）→ **想完成的事**（患者要做成什么）→ **产物**（用户手里多了什么）。**不写功能名**。
> **筛选**：删掉"换成任何癌种都成立"的伪场景。
> **状态**：草案（phase1）；`G1` 签认前不冻结。

## 1.2 失败恢复（每条场景：没资料时 / 做到一半离开时）

> **为什么单独一张表**：§1 的表格已经九列，再挤一列会读不动；而且失败恢复的判据是**两条固定问题**，适合横向比较——把 18 条并排看，哪条的降级最虚一目了然。
> **口径**：降级动作必须是**具体能做什么**，不是「提示用户重试」那种放之四海皆准的空话。若某条场景在缺资料时**真的做不了**，就如实写「不可用，给什么替代入口」，不要硬编一个假的降级。

| ID | 资料缺失时（报告没拿到 / 记不清 / 没做） | 低精力或中断时（做到一半离开） |
|---|---|---|
| **S01** | 病理报告还没拿到 → 选「**我还不确定**」即可继续，看板给通用入口（急症 / 病情整理 / 复诊准备），**不强迫归类** | 选择即存；回来仍是该状态，改线留痕 |
| **S02** | 报告不在手边 → 可先建**空条目**占位（`raw_text` 允许为空 + 标「待补」），不阻塞后续 | **逐项**核对状态按项保存；未核对项保持「待核对」，不会因为退出而变成「已核对」 |
| **S03** | 记不清第几次 → **只记「下次计划日」**，周次留空标「待补」；不得反推周次 | 一次灌注的「灌注前 / 灌注中 / 灌注后」三段**可分开记**；未完成段不生成任何结论 |
| **S04** | 上次结论没拿到 → 本次记录照样能写，结论选「**结果未出**」 | 疼痛与心情自评**可后补**；后补不覆盖已写的临床结论 |
| **S05** | 报告没出 → 选「**结果未出**」，**绝不默认阴性** | 四态未定时保持「未判定」，不自动填、不因过期而推断 |
| **S06** | 第一次手术在外院、无记录 → 可只记「**有一次 TURBT，日期待补**」 | 手术史**按次追加**，不必一次填完；未填字段保持空 |
| **S07** | 医生还没定术式 → 三种**都可以先看解释**，不强迫选一个 | 未选定即**不写入事实层**；只留在浏览状态 |
| **S08** | 型号记不住 → 可只记「换了 / 没换」，耗材留空 | 一批可只填一半字段，其余留空；**空不等于 0** |
| **S09** | 只有肌酐没有 eGFR → 先记肌酐，门槛提示写「**需要 eGFR 才能对照**」，不用肌酐硬算 | 单次检验独立成条，不要求补齐整组 |
| **S10** | **最小降级面**：四类急症判据与联系入口是**纯本地静态内容**，断网、无资料、未登录都**必须可见**（`DESIGN-30`） | 无「中断」概念——这是**随时进入**页，不保存状态 |
| **S11** | 影像没做 → 选「**未做**」，**不写「正常」**（`DESIGN-21` 四种「没有」） | 单次影像独立成条，不与他人对比 |
| **S12** | 该指标无来源 → 只记录数值，**不给解释、不给参照** | 不连线、**不补点**；窗口里只有一个点就给单点不连线的空态 |
| **S13** | 什么都不想写 → 允许**只留一句话**，不设必填 | 私密默认**关**；未显式打开则**不落库**，中途退出也不残留 |
| **S14** | 交接视图缺项 → 缺项写「**没有**」，仍能说清已知部分；**换人不问患者** | 换人接手**不必重填**，读同一份事实源；旧快照在切换时失效 |
| **S15** | 摘要缺项 → 写「**没有**」，不补不推测（`DESIGN-21`） | 问题清单随时增删；草稿保留，不因未完成而丢弃 |
| **S16** | **断网时** → 显示随包快照 + 抓取日期，明标「数据截至 2026-10-23，**非实时**」；查不到 ≠ 不存在 | 收藏与入组问题**本地保留** |
| **S17** | **没有医生原话 → 不允许存为「无应答」**，只能停在「未判定」（`DESIGN-28`，数据库层拒绝） | 状态**逐次追加**进版本链，旧判定标「已被替代」不删除 |
| **S18** | 报告没提变异型 → **保持空**，不写「无」；也可先建待问项 | 待问项可先建，病理条目后补 |

**核对**：18 条全部给出具体降级动作；其中 **S10 / S16 / S17 / S18** 四条是**红线级**（S10 断网仍可用、S16 不把快照当实时、S17 无医生原话不能判定、S18 不写「无」），已各自加约束探针或断言锁定。

> **S10 是这张表里唯一「失败恢复优先级高于功能完整」的场景**：急症页可以少一个字段，但不能因为断网或没资料就什么都不显示。记 `DESIGN-30`。
