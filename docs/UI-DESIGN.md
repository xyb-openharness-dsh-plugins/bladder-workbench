| --- | --- | --- |
| （无组名） | **看板** | 闸门（未选线）／线内看板（已选线） |
| 我的病情 | 病情整理 · 我的分型与分期 · 手术与 TURBT · 膀胱灌注 · 尿流改道与造口 · 治疗历程 | 资料库／待核对草稿／病情档案／病情汇总；病理核对／TNM 与分期／危险度；TURBT 记录／二次电切／根治性切除；灌注周期／本次记录／禁忌与中断／副作用；三术式对照／回肠造口／原位新膀胱／输尿管皮肤造口／造口日记／耗材目录；治疗线／用药与周期／疗效评估 |

**默认落点**：`检查与指标` 默认打开**分类指标卡**（3D 卡），不是裸表——这是「打开这页首屏必须有 ≥7 张卡」断言的原因。`看板` 未选线时**闸门是第一张卡**，下面按演示档案渲染全貌（避免首屏看着像没做完）。

**信息优先级**：主任务与关键状态常显；低频配置默认折叠（用原生 `<details>`，不自造 `div` + `aria`）；教学放 💡；**阻断错误与必要确认不可隐藏**。

### 业务容器宽度与宿主布局

`layoutMode = business-first`（整页 `customFrame`），`businessWidth 0.72`，与泌尿族 T0（前列腺癌）逐字段对齐。业务主区占中间，**DSH 原生会话在右侧**，不复制聊天、不占用左侧。

宽窄断点（实测）：
- `≥760px`：右侧 AI 面板内联，`splitter` 可用。
- `<760px`：面板改**覆盖式抽屉**（≤420px），业务区**不让位**，`splitter` 不出现。
- `≥700px`：指标卡两列；`<700px`：单列（不做三列以上）。
- `390px`：`documentElement.scrollWidth === 390`（无横向溢出）；导航分组标题塌成分隔线（高 ≤4px）；模态表格改卡片。

### 字体、字号三档、间距、形态

字号基线 `12.5px`，由 `--tz` 缩放：标准 `1` / 大字 `1.2` / 特大 `1.4`。

| token | 标准档 | 用于 |
| --- | --- | --- |
| `--fs-xs` | `11px` | 元信息、chip |
| `--fs-sm` | `12.5px` | 正文辅助、来源行 |
| `--fs-md` | `13.5px` | 次级正文 |
| `--fs-base` | `15px` | 正文 |
| `--fs-lg` | `17.5px` | 小标题 |
| `--fs-h2` / `--fs-h1` | `20px` / `27px` | 区块标题 / 页面标题 |
| `--fs-num` | `33px` | 指标卡数值（`tabular-nums`） |

间距 `--sp-1..7` = `4/8/12/16/20/24/32px`；圆角 `--r-sm/md/lg/pill` = `8/12/18/999px`；阴影 `--shadow-1`（卡）/ `--shadow-2`（浮层）。布局量：`--nav-w 218px` · `--topbar-h 44px` · `--agent-w 35%`。

**可读性与交互约束**：正文 `15–16px / 1.6`；辅助 `12.5–13px`；标题 `26–30px`；数字用 `tabular-nums`；**操作区 ≥44px**（触控）；`prefers-reduced-motion: reduce` 时停动效并直接给终态。

### 关键组件合同

**顶栏（三段式，2026-10-19 真机三轮反馈后的定稿结构）**
左＝品牌 + 版本 chip；中＝一句状态说明；右＝主操作按钮组（`margin-left:auto` 紧贴右缘）。
实测：`header` padding `6px 12px`；**必须有 `padding-inline-start: var(--dsh-frame-leading-clearance, 12px)`**（否则被宿主控件压住）；`gap: 10px`，按钮组内 `6px`；品牌 `12.5px/700`；版本 chip `11px/500`、`border-radius:999px`、`padding:1px 8px`、**中性灰不跟品牌色**；说明 `11.5px` + `flex:1` + `min-width:200px`；主按钮 `padding:5px 14px`、`999px`、白字。
**版本号必须在首页首屏可见**（同时出现在演示条、`#versionChip`、`#footVersion` 三处）。

**指标卡（3D 翻转）**
外卡固定高 **`276px`**（大字/特大模式统一 **`340px`**，正反一致）；圆角 `18px`；内边距 `20px`；卡间距 `16px`。
门槛：`perspective:1100px` 外卡 + 内层 `transform-style:preserve-3d` + 两面 `position:absolute; inset:0` + `backface-visibility:hidden` + 背面预转 `180°`。
`≥700px` 两列，`<700px` 单列。`role="group"` / `tabindex="0"`；隐藏面 `aria-hidden` + `inert`；`aria-pressed` 随翻转同步。
**翻转是固定高度的 3D 翻转，不是上下展开插入内容。**
> **注意**：macOS 开启「减弱动态效果」时 `transition-duration` 变 `1e-06s`（瞬间切换）——这是 `docs/24-METRIC-TREND-TAB-DESIGN.md` 的硬性要求（尊重系统设置），**不是缺陷**。

**一图秀**（C1–C12 见 `docs/ONE-CHART-SPEC.md`，实测见 `scripts/verify-one-chart.mjs`）
三条不可让步：①每条线按**该指标全期** min/max 归一化并写明不可比；②单点不连线、空窗口给空态；③治疗条与数据区分层（治疗条固定独立行，手术＝菱形 + 竖虚线）。
实测：SVG 与宿主同宽 ≤1px（无 letterbox）；治疗条刻度与同日期数据点同 x ≤2px；末点标签贴末点 ≤14px 且每序列只标一次；事件标签两两不相交（密集自动分行，行距 `17px`）；轴标签是本地日期且等于「数据点 ∪ 治疗事件」窗口两端；动画 `pathLength="1"` + `stroke-dashoffset`，点 `45ms` 递增延迟。
移动端网格轨道一律 `minmax(0,1fr)`；横向滚动**只能发生在图表容器内**（`.chart-wrap`）。

### 关键交互与状态

| 状态 | 处理 |
| --- | --- |
| 空态 | 每页给「怎么开始」的一句 + 一个入口；**不用空白页** |
| 单条 | 不连线，给单点 + 说明「只有一个点，不连线」 |
| 不可比 | 机构/方法不同 → 拆**可比组**，图例写明「N 个可比组，不跨组连线」 |
| 缺字段 | 留**空**，不填 0、不填「正常」。四种「没有」分开（`DESIGN-21`） |
| 待核对 | 草稿与事实**分区**，草稿恒标「未经核对」 |
| 错误 | 保留用户输入 + 可重试；成功才关弹窗 |
| 窄屏 | 表格改卡片、导航折叠、AI 面板改抽屉 |
| 大字 | `--tz` 缩放；卡片高度同步升到 340px（正反一致） |
| 键盘 | 全流程可 Tab 到达；模态焦点陷阱；`Esc` 关闭 |
| 减少动效 | 停动画，直接给终态 |

**信息分层**：主任务常显 → 低频配置折叠（原生 `<details>`）→ 💡 教学 → 次要操作。摘要状态源、展开与关闭、输入保留、键盘与窄面板行为：摘要折叠时保留已填输入；展开态不重置滚动。**阻断错误与必要确认的直接可见位置**：恒在内容区顶部，不折叠、不弹窗。

### 资料目录 / 会话绑定指示器

位置：**顶栏**，两个**独立**状态 pill（「资料目录」与「对话」），不合并成一个灯。
各状态：未接入（灰）/ 已激活（绿）。判定源：资料目录＝当前项目映射确认 + 目录真实可读；会话＝宿主会话 owner 与当前工作区一致。**非颜色提示**：文案直接写「已激活 / 未接入」，不只靠颜色。配置入口：点 pill 进设置页对应区块。切换中：显示「切换中」，并使**旧快照失效**。窄面板：两个 pill 缩为图标 + `title`。
> 参考 `docs/09-WORKBENCH-STATUS.md`。**保存成功 ≠ 连接就绪**，两者不互相替代。

### DSH 原生 AI 对话

顶栏拉起按钮文案：「**打开 AI 对话**」/「**收起 AI 对话**」；三态：连接中 / 已连接（原型）/ 不可用。
面板**默认关**；**可独立隐藏与重开**，隐藏**不结束会话、不清空筛选与表单滚动、不丢草稿**。
宽度：默认 **35%**，范围 **25%–45%**；键盘 `←/→` 步进 **2%**，`Home/End` 到边界；`role="separator"` + `aria-valuenow/min/max` + `tabindex="0"`；宽度写 `localStorage`，读回经 `clampAgentWidth()`。
偏好存储：`localStorage`（键见 `prototypes/v0.1/app.js`）；正式项目改由宿主 profile 持久化。
`layoutMode = business-first`（CustomFrame）→ 使用**右侧原生面板 + splitter**；宿主不支持时**列出限制与替代**，**不得自制聊天窗冒充**。
`<760px`：改覆盖式抽屉（≤420px），业务区不让位。

**上下文草稿四条不可让步**（`AC-41`–`AC-43`）：
1. **只抄记录**，缺项写「没有」，不补不推测；
2. 「已确认」**只表示转录核对**，界面必须写明「不等于医学审核」；
3. **私密 fail-closed**，未显式勾选绝不带入；勾选后标「本次已勾选带入」；
4. **草稿不得带本机资料目录路径（含用户名）**。

送达：`postMessage({type:'bladder:agent-draft', prompt})`，面板侧**同时校验** `event.source === iframe.contentWindow` 与 `event.origin === location.origin`；长度上限 **8000**；**只调 `setDraft`，不调提交/发送**。空态不给入口。脱离宿主退化为「**复制草稿**」并写明没有 AI 面板。
> 引用 `prompts/DSH-AGENT-PANE-INTEGRATION.md`。**未接入 DSH，上述面板行为均为原型状态，标记「未验证」。**

### 长内容弹窗 / 抽屉

**固定外壳**：标题与关闭按钮**始终可见**，**只有内容区滚动**；多选工具与主要确认操作按需固定。高度上限 `min(86vh, 720px)`。表单关联：`aria-labelledby` 指向标题。背景滚动锁定。**窄窗 / 大字**下仍可退出——不让整张弹窗或背景页面代替内容滚动。键盘：`Esc` 关闭、焦点陷阱、关闭后焦点回到触发元素。
预留/删除按钮**不在同一行相邻位置**，避免误触。
> ⚠️ 已知未修：`<600px` 时测试表曾被弹窗与 `td` 最小宽度撑出溢出，已修列宽优先级，**未在新窄宽下重测**。

### 键盘、焦点、减少动效、触控

`aria-pressed`（3D 卡）、`role="separator"` + 三值（splitter）、`aria-hidden` + `inert`（隐藏面）、`role="group"`（卡组）已实现并有断言。焦点可见环用 `--wb-action`。`prefers-reduced-motion` 停动效。操作区 ≥44px。**未做的**：完整的焦点顺序人工走查、屏幕阅读器实测（未验证）。

### 设置

入口：左侧导航最末「其他」分组的**设置**（与 14 项一级页视觉分隔）。
页面分五块：①患者资料目录（主目录缩成 `~`；切换后旧快照失效；卸载不删业务数据）②文档解析 MinerU ③指南与数据包来源与版本（`docs/SOURCES.md`）④字号三档 ⑤关于（版本号须与 `package.json` / `VERSION` / 顶栏 chip 三处同源）。
**API 凭据只显示来源与已配置状态，不显示明文**：`{configured, source: file|env|none, sourceLabel, masked}`。唯一密钥文件 `mineru.json`；Token 优先级 **显式 > 文件 > env**；原文**永不**回界面/日志/错误消息。
云端授权说明与解析失败降级：一期末页只做**骨架，不联网**；失败时给可重试错误 + 手工抄录替代路径。
保存/取消/错误恢复：改动**显式保存**；保存失败**保留输入**并给可重试错误；**成功才关弹窗**；Token 输入框保存后清空。
`.gitignore` 必须含 `.secrets/`。

## Taste Seed 风格决策（按需）

目标体验感受及用户确认依据：**无用户确认依据**。推导目标——「清透、克制、像医院走廊的采光，不像保健品广告」；因为受众是中老年患者与照护者，**可读性优先于装饰**。
实际阅读来源/文件/提交（未读取则明确）：**未读取** `docs/08-TASTE-SEED.md` 的风格种子库文件（该文件在脚手架中以说明为主）。故本节不是种子库选型结果，而是本项目自定方向，**不得声称来自种子库**。
主方向 / 可选辅助方向 / 选择理由：主方向「青泉（水色）」——膀胱癌的核心隐喻是**尿路与液体**，用水色比用脏器插图更克制也不冒犯；辅助方向「对偶暖赭」——用于治疗事件与强调，避免全冷色显得疏离。

| 维度 | 具体 UI 参数/token | 可读性与交互约束 | 实际预览结果 |
| --- | --- | --- | --- |
| 色彩 | 品牌 `#1793A6`／行动 `#0F6E7D`／暖赭 `#C96A1E`；纸 `#F6FAFB`、卡 `#FFFFFF`、正文 `#1E3A42` | 正文对纸底对比 ≥7:1；**分类变量不做好坏着色** | 已实测（`_shots/`） |
| 光影 | `--shadow-1`（卡）/ `--shadow-2`（浮层）；**不用渐变** | 阴影只做层次，不做装饰 | 已实测 |
| 线条 | 描边 `--wb-line #CFE0E5`、浅线 `#E6EFF2`；1px | 分隔靠线不靠底色块堆叠 | 已实测 |
| 构图 | 顶栏 44px 三段式；导航 218px；内容区留白 `--sp-5/6/7` | 版本号首屏可见；辅助信息不抢主体 | 已实测 |
| 情绪 | 克制、清透；品牌装饰每页 1–3 处 | 不恐吓、不用红色警示做装饰 | 已实测 |

开发者反馈：接受/拒绝的具体处理、原因与修订：见 `docs/PROTOTYPE-REVIEW.md`（每轮用户原话 + 处理）。
与已确认原型或社区规范的冲突及处理：**无冲突**。品牌色与社区既有病种站不共用色板（各病种站独立配色），符合社区规范。
