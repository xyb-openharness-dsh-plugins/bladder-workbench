| 未知日期/文本值/同日多次 | 缺测**留 NULL 不写 0**（`CHECK` 强制三项至少一项非空）。`absence_state` 六态分开：`not_tested`（问过但没做）/ `not_detected`（做了没检出）/ `negative`（阴性）/ `failed`（做了失败）/ `pending`（做过没拿到结果）/ `vus`（意义未明）。界面侧对应「四种『没有』」（病情汇总页）：问过但没这项检查→没有｜做过但报告还没拿到→结果未出｜报告上有但没看懂→照抄原文+标「待与医生确认」｜私密未勾选带入→本次未带入。**四种不能合并成一个「无」**。同日多次：**保留多条、不合并、不排序当"前次"**（无时间顺序依据），卡片正面只取 `observed_on` 最近的一条并在详情里逐条列出。 |
| 最近报告ID/修订版聚合规则 | `observations.source_ref_id → source_refs → documents(sha256)`。同一份报告改版**不覆盖**，新增 `source_ref` 并在 `change_log` 留痕；`documents` 上 `UNIQUE(subject_id, sha256)` 防重复入库。卡片正面显示「共 N 次记录 · 最近 YYYY-MM-DD」，点开逐条可回源。**原型未实现报告 ID 与修订聚合（MT11＝未实现）**，phase1 止点；schema 结构已就位。 |
| 卡片高/字阶/2列→1列阈值/大字 | 标准档 **276px**、大字档 **340px**（正反一致，`scrollHeight <= clientHeight` 实测不裁切）；容器 ≥700px 两列、<700px 单列，**不做三列以上**；字号三档 12.5 / 15 / 17.5px。 |
| 3D翻面、来源点命中、键盘/读屏 | `perspective: 1100px` 外卡 + `transform-style: preserve-3d` 内层 + 两面 `position:absolute; inset:0` + `backface-visibility: hidden` + 背面预转 180°；翻面＝`[data-flipped=true]` 时 `rotateY(180deg)`，**是固定高度 3D 翻转，不是上下展开**。键盘：卡片 `tabindex=0` + `Enter`/`Space` 翻面。读屏：`role="group"` + `aria-label` + **`aria-pressed` 说出翻转态**（这是实测暴露后补的缺口），隐藏面 `aria-hidden` + `inert` 不进 Tab 序。来源点：背面迷你折线的圆点带 `<title>`，**点圆点只弹来源、不翻回正面**（实测发现点击冒泡会把卡翻回去，已修）。减少动效：系统开启时直接给终态。 |

## 与通用模板的偏离（**未批准**，待 G2 裁决）

| 模板假设 | 本项目实际 | 理由 |
| --- | --- | --- |
| 「病情整理 › 指标检测」五个页内 Tab | 「检查与指标」独立成一级页，4 个页签 | 指标在本癌种要跟治疗事件（TURBT / 灌注 / 改道）对照着读，放进"病情整理"里层级太深；一图秀另立一级页 |
| 指标选择上限 4 条 | **6 条** | 要同时看肾功能与电解质/血常规，4 条不够；实测一行放得下 7 个复选框（同 `docs/ONE-CHART-SPEC.md` 的 R7） |
| 康复类变化用绝对值 | **所有变化文案都不得用百分比** | 膀胱癌**没有康复类指标**（无上肢臂围这类），按同一原则换算：所有变化文案必须带绝对单位（同 `docs/ONE-CHART-SPEC.md` 的 C7） |
| 图内缩放、固定详情面板 | 未实现（只有时间窗按钮 + `title` 兜底） | phase1 止点；同 `docs/ONE-CHART-SPEC.md` 的 R8/R9 |
