## 患者/社区数据目录

当前目录状态及真实判定源：未选择/检查中/就绪/故障。原生选择、取消无副作用；路径存在不等于初始化成功。目录更换、旧资料处理、复制/迁移/备份/失败回滚：**切换只改指向，不搬文件、不删旧目录**；旧快照立即失效并重扫，扫完才显示「就绪」；扫描失败保留旧指向并给可重试错误（**不静默回退到默认目录**）。不重置患者数据。患者资料与工作台配置、临床参考数据包分开存储。**空目录/无权限/路径不存在**都是显式状态，不显示成「就绪」。**未验证**：真实文件系统权限与超大目录的扫描耗时未实测。

## 外部解析与凭据

可选服务、地区/服务方、社区共享凭据来源与可用状态：本项目**唯一云能力是 MinerU 文档解析**，服务方为 MinerU（地区：中国大陆），**一期只做骨架、不联网**。社区共享凭据：starter/社区发行包**当前未提供**，因此设置页不预置任何默认 Token，一律显示「**未配置**」。当 starter/社区发行包可提供共享凭据时可作为默认来源；只显示“可用/失效/不可用”与来源，不展示明文。不得复制密钥到业务SPEC、HTML、示例、截图、日志、导出、客户端状态或患者资料。正式UI允许用户覆盖/清除自己的凭据；持久化位置、权限、脱敏与轮换：唯一实现层 `dsh/settings.js`；唯一密钥文件 `mineru.json`（默认落用户目录，环境变量仅兜底且**排在其后**）；权限 `0600`；界面只回显**掩码**与来源（`file` / `env` / `none`）以及文件路径；轮换 = 覆盖保存或 `{action:"clear"}` 清除，**无自动轮换**（无此必要）。错误码：`400 invalid_token`（空 / <8 / >1024 / 含空白 / 非 `[A-Za-z0-9._-]`）、`500 settings_write_failed`、`405`。`.gitignore` 必须含 `.secrets/`。

本地模式/受支持格式：**本地模式是一期唯一模式**（PDF/DOCX/TXT/MD 由用户后续手动抄录，不解析）。云解析（MinerU）**未接通**，界面标「未配置」并给申请地址链接，不真联网。云处理前要显示本次选中的文件、接收服务、目的、限制/留存说明，按文件/批次取得主动授权。设置里记住的偏好不替代敏感操作前的确认。拒绝授权、超时、限流、凭据失效和服务停机时的降级/重试/原件保留：一律**降级到手动抄录**并保留原件，绝不因解析失败而丢资料；重试由用户显式触发，`TIMEOUT` / `NOT_ENABLED` / `NEEDS_SETUP` **不得推出「不存在」**。

## 保存与可访问性

草稿/保存/取消/未保存关闭提示/保存失败：改动**需显式保存**；保存失败**保留输入**并给可重试错误，成功才关弹窗；Token 输入框保存后**清空**。错误恢复与旧配置保留：写失败时旧配置**不动**，不做部分写入。标题/关闭、唯一滚动区、固定动作、键盘/焦点/读屏、窄窗/大字、减少动效和触屏：长内容弹窗采用**固定外壳**（标题与关闭按钮始终可见，**只有内容区滚动**）；操作区 ≥44px；焦点顺序与视觉顺序一致；窄窗单列；大字模式基线 12.5/15/17.5px；`prefers-reduced-motion` 下停动效；触屏可拖动分隔器。
