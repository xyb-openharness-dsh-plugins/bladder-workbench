## 1 定义（`definition`）

膀胱癌是发生在膀胱的恶性肿瘤，最常见的组织学类型是尿路上皮癌。本项目把「肿瘤有没有长到肌层」
作为第一条分野线：NMIBC 与 MIBC，两条线的术式、灌注与复查节奏不同；未确认的人可选「我还不确定」。

- 分野口径：以病理报告「肌层是否受累」为准；未写肌层时标「待澄清项」（AC-05），不当作正常结论。
- 病理与分级：记录病理类型、分级、分期断言（医生原话）与危险度标记；不生成分级或分期换算。
- 两条线不并存：选 NMIBC 出灌注 / 膀胱镜复查 / 尿细胞学；选 MIBC 出改道 / 肾功能 / 造口日记；改线留痕不覆盖。
- 零倾向：项目明确「保膀胱」不得被写成默认正确选项；本台不做这种取向的表达。
- 急症语境：血块与尿潴留、BCG 全身感染、造口缺血梗阻、无尿与腰痛单列，只给联系入口与判据原文。

## 3 目前治疗全景概要（`landscape`）

按分野与治疗段落分组，只列指南与共识里出现过的手段，不排序、不比优劣、不含剂量与疗程。

### 3.1 非肌层浸润（NMIBC）
- TURBT：记录「完全切除 / 不完全切除 / 未提及」的原文。
- 二次电切：NMIBC 可能加做一次，MIBC 路径里也常出现；是否做由手术记录与病理决定。
- 膀胱灌注：按「即刻（术后 24 小时内）/ 诱导（每周 1 次 × 6～8）/ 维持」三段记录；演示方案为 BCG（卡介苗），禁忌与中断单独记录。
- BCG 应答：必须有医生原话；没有原话只能停在「未判定」。

### 3.2 肌层浸润（MIBC）
- 根治性膀胱切除 + 尿流改道重建（作为独立事件记录）。
- 尿流改道三术式（零倾向对照）：回肠通道造口（Bricker 术）、原位新膀胱、输尿管皮肤造口。
- 保膀胱路径：2022 / 2024 保膀胱共识记录复查间隔；2024 版列极高危四项构成（BCG 无应答、血管淋巴管侵犯、变异组织类型、前列腺尿道侵犯），本台只列构成，不给处置方向。

### 3.3 晚期 / 转移后
- 系统治疗按线记录方案、周期与疗效评估。
- 临床试验按「NMIBC 或膀胱内治疗 / MIBC 或围手术期 / 晚期或转移」分层展示，不排优先级。

### 3.4 贯穿全程
- 肾功能与上尿路监测：肌酐、eGFR、核素肾图分侧、上尿路影像；顺铂不耐受门槛写作 CrCl <60 ml/min 或 eGFR ≤60 ml/min（来源写作 2022 / 2024 保膀胱共识）。
- 复查：膀胱镜 + 尿细胞学、上尿路影像，只记「约在哪天、做了没有」。

## 7 本项目教训

- **这个原型没有 `.top-actions`**：starter 的模块会依次找 `.top-actions` → `.topbar` → `header`。
  本项目两者都没有，最后落到 `header.wb-topbar`。这是预期行为，不是漏写，也没有为了对齐别的项目去改原型的顶栏结构。
- **共识机构名不能靠猜**：演示数据里只写「2022 保膀胱共识」「2024 保膀胱共识」「2021 灌注共识」，
  没有机构全名。第一版草稿想写「中华医学会泌尿外科学分会」，撤掉了——**年份是项目里的，机构不是**。
  表里因此写「机构未核实」，并把项目原话一起放进去，方便后续核对。
- **「应首选根治性膀胱切除术」是共识原文，不是本台结论**：2024 版极高危四项后面紧跟着这句处置方向。
  疾病概要只列四项构成，不复述「首选」，否则读者会把一段共识的判断当成给自己的方案。
