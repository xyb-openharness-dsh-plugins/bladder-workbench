### 差异化矩阵草案（防换名复用，至少 3 条）
1. 场景：**膀胱癌不是一种病，是两条完全不同的病** —— NMIBC（非肌层浸润，约 3/4 患者，治疗目标是"保住膀胱"）与 MIBC（肌层浸润，治疗目标是"活下来并学会带着改道生活"），分野直接回答"我还有没有膀胱" → 功能：NMIBC/MIBC 双路径分野页（Ta/T1/Tis 三态、**WHO 1973 与 2004/2022 两套分级并列不混**、危险度分组、是否见肌层）→ 验收：G1 场景签认 + G3 数据契约冻结
2. 场景：**膀胱灌注（BCG / 化疗灌注）是家族里任何癌种都没有的模块** —— 诱导 6 周 + 维持最长 3 年、BCG 断供恐惧、化学性膀胱炎与全身感染、憋尿时间与灌注后饮水 → 功能：灌注专属档案（药物/方案/周次/憋尿与饮水/副作用分级/中断原因与断供记录）→ 验收：G2 逐页走查 + 文案红线通过
3. 场景：**膀胱镜复查是"检查本身成为心理事件"** —— 高危每 3 个月一次、终身随访，"每次镜检前一周睡不着" → 功能：复查档案（方式：柔性/硬性/荧光/麻醉 + **疼痛评分** + 结果 + **下次复查计划**）+ 复发恐惧的独立记录位 → 验收：独立轨道，不并入指标趋势
4. 场景：**尿流改道三选一是三种不同的生活**（回肠造口 Bricker / 原位新膀胱 / 输尿管皮肤造口），不是"造口"一个标签：一个要管底盘与渗漏，一个要管控尿训练与间歇导尿，一个要管输尿管支架与吻合口 → 功能：三种术式各自独立页签 + 造口日常（底盘型号与更换周期/皮肤并发症/渗漏/气味/夜间集尿器/游泳洗澡旅行过安检）+ 新膀胱控尿与间歇导尿记录 → 验收：G2 三页逐页走查，隐私分级用例通过
5. 场景：**尿细胞学的"非典型/可疑"最折磨人**（自然尿 vs 膀胱冲洗、FISH/NMP22/BTA），患者把"非典型"当阳性或当阴性；同时 2–5% 患者会上尿路尿路上皮癌，根治术后还有输尿管吻合口复发，是**家族里唯一的"另一个器官长期监测"** → 功能：细胞学四态（阴性/非典型/可疑/阳性）+ 标本类型与来源 + 上尿路监测独立页（CTU/IVU/输尿管镜/肾积水）→ 验收：G3 数据契约冻结
6. 场景：**肾功能是膀胱癌治疗的硬门槛**："医生说肌酐高打不了顺铂"必须听懂；根治术后单侧肾、肾积水、输尿管狭窄、改道后回肠切除导致的 **B12 缺乏与代谢性酸中毒**，跨十年累积 → 功能：肾功能与顺铂话题（eGFR/肌酐/分肾核素肾图/肾积水与引流 DJ管或肾造瘘）+ 改道后代谢长期负担（B12/碳酸氢盐/氯/反复尿路感染与结石）→ 验收：独立指标组，机构或方法不兼容不串线

**急症与安全边界（不写成免责声明）**：血块致膀胱填塞/尿潴留、**BCG 全身感染（灌注后 24–72h 高热寒战不缓解 = 立即就医）**、造口缺血/梗阻、无尿伴腰痛（输尿管梗阻）、化疗后中性粒细胞下降伴发热。

### 为什么这个病种现在需要
① 规模：中—高，男性泌尿系统最常见恶性肿瘤之一；② 信息差：极高 —— NMIBC/MIBC 分野、TURBT 与"未见肌层"、两套分级体系、灌注周期、造口三选一、细胞学四态，几乎全压在门诊几分钟里；③ 危重与时间压力：MIBC 决策窗窄（新辅助化疗后根治术有明确时间窗），根治术与改道是**不可逆的身体重构**，术前准备的信息质量直接决定术后生活；④ 长病程的另一半：NMIBC 患者要终身每 3–6 个月复查膀胱镜，复发率 50–70%，是"长期把记录理清楚"的典型；⑤ 沉默缺口：造口、性功能、控尿与尿失禁问题患者极少主动开口，家属也不知道该问，是这个癌种最被低估的部分。
