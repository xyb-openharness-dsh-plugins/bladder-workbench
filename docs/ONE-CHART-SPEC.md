## 1. 三个合同

| 合同 | 本项目口径 | 写在哪 |
| --- | --- | --- |
| 可比性 | ① **分类变量不进折线**：尿细胞学（阴性/非典型/可疑/阳性）是四态分类，只在独立页签列表呈现，绝不画成折线或布尔切换。② 同一指标**换机构或换方法即断线**，按 `机构·方法` 拆可比组，组内才连线；跨组不给连线也不给「上升/下降」结论。演示档案里肾功能肌酐在 2026-10-08 从「演示检验科·酶法」换到「演示社区医院·苦味酸法」，即按此拆成 2 组。③ 不同指标之间一律不可比，只共享时间轴。 | `docs/SPEC.md` M13、`docs/UI-DESIGN.md` |
| 归一化 | 每条线按**该指标全期 min/max** 单独归一化后铺满纵向绘图区；因此「两条线在图上等高」不代表数值接近。零跨度（全期同值）兜底为绘图区垂直居中，不除零。坐标轴只标日期，不标数值刻度。 | `docs/UI-DESIGN.md` |
| 事实源 | 一图秀、指标卡、复诊摘要、导出**共用同一个指标目录**（`METRICS` + `metric_definition` 版本化）与同一份按时间排序的观察记录（`observation` / `measurement`）。分组名与顺序两页一致（检查与指标页 / 一图秀页）。页面不各存一份数据。 | `docs/SCHEMA.md`、`docs/DATA-FLOW-SPEC.md` |

## 2. 指标清单

实现中的 `METRICS`（`prototypes/v0.1/data.js`）。精度指展示小数位。

| 编码 | 名称 | 分类 | 单位 | 精度 | 变化口径 | 可比性分组 |
| --- | --- | --- | --- | --- | --- | --- |
| `egfr` | eGFR | 肾功能 | mL/min/1.73m² | 整数 | 绝对差 + 上次值与日期 | 按机构·方法（演示：1 组·CKD-EPI） |
| `cr` | 肌酐 | 肾功能 | μmol/L | 整数 | 绝对差 + 上次值与日期 | **2 组**：演示检验科·酶法 / 演示社区医院·苦味酸法 |
| `hb` | 血红蛋白 | 血常规 | g/L | 整数 | 绝对差 + 上次值与日期 | 按机构·方法（1 组·血细胞分析） |
| `anc` | 中性粒细胞绝对值 | 血常规 | 10⁹/L | 1 位小数 | 绝对差 + 上次值与日期 | 按机构·方法（1 组·血细胞分析） |
| `alt` | ALT | 肝功能 | U/L | 整数 | 绝对差 + 上次值与日期 | 按机构·方法（1 组·速率法） |
| `weight` | 体重 | 营养 | kg | 1 位小数 | 绝对差 + 上次值与日期 | 机构不适用（家用体重秤） |
| `pain` | 疼痛自评 | 症状自评 | 分（0–10） | 整数 | 绝对差 + 上次值与日期 | 不适用（本人自评） |
| `cytology` | 尿细胞学 | 尿检 | —（四态） | — | **不进折线**，只列表 | 分类变量，无归一化 |

- 指标总数：**7 项可折线** + 1 项分类（尿细胞学）。远低于 30 上限，一期不加搜索框。
- 默认选中：**`egfr` + `hb`**（肾功能 + 血常规各一，两条线分野都要看）。
- 颜色：按分类取语义色（肾功能 `--d-renal`、血常规 `--d-blood`、肝功能 `--d-lyte`、营养 `--d-nutrition`、症状 `--d-symptom`）。**分类变量绝不按好/坏着色**；颜色不是唯一区分手段（图例同时给名称与单位）。
- 变化口径统一为**绝对值 + 单位**，不用百分比（见 R5 与 C7）。

## 3. 治疗节点

| 类型 | 呈现 | 数据来源 | 备注 |
| --- | --- | --- | --- |
| 手术（TURBT） | 菱形 + 贯穿竖虚线 | `TREATMENTS`（演示） | 时点事件，不占 lane |
| 膀胱灌注（BCG 诱导开始） | 菱形 + 贯穿竖虚线 | `TREATMENTS`（演示） | 时点事件，不占 lane |
| 灌注取消 | 菱形 + 贯穿竖虚线 | `TREATMENTS`（演示） | **取消也是要记的事件**，不是空白 |
| 药物治疗 / 放疗 | 未实现（独立 lane 色条） | — | 见 §8 偏离 3 |
| 其它 | 无则不画 | — | |

演示档案含 **3 个**治疗事件。治疗条固定在绘图区上方**独立一层**，与数据面分层；数据点与之同日期时 x 坐标对齐（实测 ≤2px）。

## 5. R1–R12 逐条核对

| 规则 | 结论 | 证据（DOM/断言输出） | 偏离理由 |
| --- | --- | --- | --- |
| R1 独立归一化 + 不可比说明 | 符合 | C1：两条 path bbox 高 166.0 / 166.0，差 0.0%；页头常显「每条线按该指标全期 min/max 归一化，所以不同线之间不可比」 | |
| R2 单点不连线 + 空态 | 符合 | C2：`path=0 dot=1`；C3：`empty=true reason="所选时间窗内没有记录"`，`.plot-empty` 呈现 | |
| R3 治疗条分层 | 符合 | C4：隐藏 `.treat-lane` 后 `path[d]` 字符串逐一比对一致；DOM 上 `.treat-lane` 与 `.plot` 为兄弟节点 | |
| R4 只标末点 + 避让 | 符合 | C5：2 条线 / 2 个末点标签；C6：4 个 text 全部在 viewBox 内；距右边界 <46px 改 `text-anchor=end` | |
| R5 变化口径按类型 | 符合 | C7：7 处变化文案全部带绝对单位，含百分比 **0** 处。通用规范里 C7 的原形是「康复类用绝对值」（乳腺癌臂围），**膀胱癌没有康复类指标**，故按同一原则换算成本癌种适用形式 | |
| R6 `pathLength=1` 动画 | 符合 | `charts.js` 线用 `pathLength="1"` + `stroke-dashoffset` 递增延迟；C10 在 `prefers-reduced-motion: reduce` 下 offset 直接为 `0px` | |
| R7 ≤4 指标 + 可滚动 + 折叠 | **偏离** | 上限为 **6** 且无需滚动：筛选区一行放得下（7 个复选框），窄屏自然换行 | 见 §8 偏离 4 |
| R8 时间窗/缩放/图例一致 | **部分偏离** | 时间窗四档与图例（名称+单位+可比组数）均一致；**缩放未实现** | 见 §8 偏离 2 |
| R9 固定详情 + 回源 | **偏离** | 数据点用 SVG `<title>` 悬浮显示 `日期：值 单位`，无固定详情面板、无回源链接 | 见 §8 偏离 1 |
| R10 `minmax(0,1fr)` + 独立滚动 | 符合 | C9：390 宽下 `documentElement.scrollWidth === 390`、`body === 390`；横向滚动只发生在 `.chart-wrap` 内（`sw 584 / cw 258`） | |
| R11 减少动效保留终态 | 符合 | C10：`reduced-motion=true`，两条线 `stroke-dashoffset=0px`（终态可见，不是隐藏） | |
| R12 可访问性 | 符合 | C11：翻转前后 rect `Δx=Δy=Δw=Δh=0.00`，内层 `matrix3d`；C12：单卡 `aria-pressed=true`，其余 6 张 `false`；隐藏面 `aria-hidden` + `inert`，卡片 `role="group"` `tabindex="0"`，Enter/Space 可翻转 | |

## 6. 验收断言 C1–C12

| 编号 | 断言 | 结果 | 实测值 |
| --- | --- | --- | --- |
| C1 | 量纲差异大的两指标都占满纵向区 | 通过 | 两条 path bbox 高 166.0 / 166.0，差 0.0%（<10%） |
| C2 | 单点不连线（无 path，恰 1 个圆点） | 通过 | path=0 dot=1 |
| C3 | 空窗口有空态（不是空 svg） | 通过 | empty=true reason="所选时间窗内没有记录" |
| C4 | 关治疗节点曲线不变（path[d] 字符串完全一致） | 通过 | 2 条 path，隐藏治疗泳道后逐一比对一致 |
| C5 | 每序列只有一个数值标签 | 通过 | 2 条线 / 2 个末点标签 |
| C6 | 标签不越界（所有 text bbox 在 viewBox 内） | 通过 | 4 个 text，越界 0 |
| C7 | C7（本癌种换算）变化文案带绝对单位、不用百分比 | 通过 | 7 处变化文案全部带单位，含百分比 0 处｜例：4 mL/min/1.73m² · 上次 70（2026-10-08） ／ 3 g/L · 上次 121（2026-10-08） ／ 0.3 10⁹/L · 上次 2.7（2026-10-08） |
| C8 | 时间窗联动（切近 3 月后首刻度右移、点数减少） | 通过 | 全部：首刻度 2025-06-20 / 16 点 → 近 3 月：首刻度 2026-07-23 / 8 点 |
| C9 | 390 宽无横向溢出（scrollWidth === 390） | 通过 | documentElement=390 body=390；图表滚动容器 584/258 |
| C10 | 减少动效下曲线可见（stroke-dashoffset 为 0，直接给终态） | 通过 | reduced-motion=true，offset=0px offset=0px |
| C11 | 翻转不位移（翻转前后 rect 完全一致，内层含 matrix3d） | 通过 | Δx=0.00 Δy=0.00 Δw=0.00 Δh=0.00；transform=matrix3d(-1, 0, 0, 0, … |
| C12 | 翻转状态独立（单卡 aria-pressed=true，其他 false） | 通过 | aria-pressed=[true,false,false,false,false,false,false] |

> 本节 C1–C12 由 `scripts/verify-one-chart.mjs` 在真浏览器实测生成，
> 复现：`node scripts/verify-one-chart.mjs --write`。实测时间：2026-10-23。
>
> 其中 **C12 是实测暴露出来的真缺口**：卡片原本只有 `role`/`tabindex`/`aria-label`，
> 翻转时只改了 `aria-hidden` 与 `inert`，**没有把卡片自身的状态说出来** ——
> 读屏用户按了回车，听不出「翻了」。已补 `aria-pressed` 并把该断言锁进
> `scripts/verify-prototype.mjs`（防回退）。

## 7. 指标卡

| 项 | 本项目值 |
| --- | --- |
| 卡片高度 | **固定 276px**（标准档）/ **340px**（大字档）；正反两面同高，窄屏两列、<700px 单列 |
| 背面内容 | 固定尺寸迷你折线：**按容器实测宽高 1:1 渲染**（不拉伸），含全期范围、机构·方法、可比组、是否启用分级对照 |
| 正面内容 | 指标名 + 分类 + 最近值/单位 + 与上次的绝对差及上次值与日期 + 参考范围标尺（浅色区 = 报告给出的参考范围，注明「不做好坏判断」）+ CTCAE 对照徽章（仅对有绝对数值界限的项）+ 记录次数/最近日期/来源 |
| 单点文案 | 「仅一次记录，无法比较」 |
| 翻转态存储 | **单卡布尔值**（`dataset.flipped`）—— 一次只翻一张，不做多张同时翻转 |
| 可比组文案 | 正面 `.mc-meta` 写「可比组 N 个（不跨组连线）：机构·方法 n 次 / …」（见 §1 可比性合同） |

## 8. 已知偏离

| 规则/断言 | 偏离内容 | 理由 | 批准人 | 日期 |
| --- | --- | --- | --- | --- |
| R9 固定详情 + 回源 | 数据点只给 SVG `<title>` 悬浮，无固定详情面板、无「查看来源」入口 | 一期止点只到 HTML 原型，回源需要事实层与 `source_ref` 接通（G3 之后）；悬浮已能读出日期/值/单位，不足以支撑「回源」但不误导 | **未批准**（待 G2 讨论） | — |
| R8 缩放 | 未实现 40–100 缩放与右端锚定 | 演示数据仅 16 个月、7 项指标，时间窗四档已够用；缩放需要重做 x 比例尺与刻度避让，一期不引入未验证交互 | **未批准**（待 G2 讨论） | — |
| R3 疾病治疗 lane | 未实现药物治疗/放疗的独立 lane 色条，治疗事件统一用「菱形 + 竖虚线」 | 膀胱癌本癌种的核心治疗事件是**时点事件**（TURBT、灌注开始、灌注取消），不是持续期色条；真正需要 lane 的是灌注的「诱导 6 周 / 维持最长 3 年」区间，而该区间的**维持次数与间隔在已精读的 6 份共识文献里只有图片未取到原文**，不编造数值 | **未批准**（待补采来源） | — |
| R7 指标上限 | 上限 6 条线（通用规范写 ≤4） | 膀胱癌患者随访要同时看**肾功能（顺铂门槛）与电解质/血常规**，两条线分野交叉，4 条不够；实测一行放得下 7 个复选框，不需要滚动或折叠 | **未批准**（待 G2 讨论） | — |
