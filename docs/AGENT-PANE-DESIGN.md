## 0. 一句话状态

**原型的 AI 面板是「状态稿」，不是接入。** 面板里没有真实 DSH 会话 ——
它演示的是**布局、断点、宽度、草稿预览**这四件事，并明确标注「此处是 DSH 原生会话面板的占位」。
真实接入**未验证**（未接入 DSH），因此本页所有「已实现」都只指**原型可演示**，
不等于宿主接通。**不得据本文档声称 Agent 面板已集成。**

## 2. 断点（按**容器宽度**，不按整窗宽度）

| 容器宽 | 布局 |
| --- | --- |
| ≥ 760px | 业务主区 + 右侧面板；面板默认 **35%**，可拖 **25%–45%** |
| 620–760px | **顶栏三段式换行成两行**；左侧导航**仍显示图标与文字** |
| < 620px | 导航**才**折叠文字 |
| < 760px（面板） | 面板改**覆盖式抽屉 ≤420px**：业务区**不让位**，**splitter 不出现** |

> 合同要求「断点须用工作台容器宽度而非整窗宽度计算」。原型用 `.wb-root` 容器查询/媒体查询实现，
> **未在真机窄窗下逐档实测**（`file://` + 无头浏览器量过 390 / 1440 两档）。

## 3. 上下文草稿的四条不可让步（已写进原型文案与断言）

1. **只抄记录**，缺项写「**没有**」，不补不推测；
2. 「已确认」只表示**转录核对**，必须同屏写明「**不等于医学审核**」；
3. **私密 fail-closed**：私密项默认不带入，勾选后标「**本次已勾选带入**」；
4. **草稿不得出现本机资料目录路径或用户名**。

> 第 4 条有断言锁定（全文 grep `Users/` 与本机用户名 → 0 命中）。

### 范围边界（`GET /api/agent/context?scope=…` 的口径，一期只做前端预览）

| 范围 | 带 | 不带 |
| --- | --- | --- |
| 图表页 | 当前选中序列（含单位、方法、「方法变了不可直接比较」）、同段治疗节点 | 未选中的序列、未核对数据 |
| 就诊准备 | 问题清单、未完成待办 | 默认不带私密项 |
| 核对 / 草稿页 | **仅已确认入库的事实** | 未确认候选只报**条数**，不带内容 |
| 全站 | 来源、时间、核对状态、缺项 | 本机路径、用户名、私密未勾选项 |

**草稿长度上限 8000 字符**；只调 `setDraft`，**不调提交/发送**；
送达用 `postMessage({type:'bladder:agent-draft', prompt})`，
面板侧同时校验 `event.source === iframe.contentWindow` 与 `event.origin === location.origin`。

## 4. 未验证 / 不冒充（接入前必须补齐）

1. **真实 DSH 会话未接**：原型面板内容全部标「宿主模拟 / 非真实 DSH 会话」；
2. **contract 5/7 两条零实现**（自动创建衔接、草稿冲突）—— 这两条是**接入期的高风险项**，需在目标 Desktop RC 上实测；
3. **四态状态文案**（未打开 / 正在连接 / 已连接 / 暂不可用）只做了两态；
4. **原生 conversation 组件**只能在指定 Desktop/Harness RC 实机里验证，**未知接口不猜名调用**；
5. **不在业务 WebView 里仿制聊天窗口**，不自行实现第二套消息记录 —— 原型里的面板是**占位**，不是第二套实现。
