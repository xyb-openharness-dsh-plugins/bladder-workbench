# 需求起点

来源：初始化配置。用户、场景和流程是有效的SPEC互动素材；继承会话中已有明确确认，其余不能仅因配置通过校验就当成设计定稿或研究验证。

目标用户：新确诊或正在长期随访的膀胱癌患者本人，以及代记资料的配偶/子女照护者。两条主线人群并列：① NMIBC 非肌层浸润、正在做膀胱灌注与终身膀胱镜复查的保膀胱患者（中老年为主）；② MIBC 肌层浸润、已做或即将做根治性膀胱切除与尿流改道的患者及其主要照护者（造口日常需要照护者接手）

场景：患者因为一次无痛肉眼血尿做了 TURBT，拿到一份写着「高级别尿路上皮癌，Ta/T1，未见肌层」的病理报告，完全不知道该不该切膀胱；正在做 BCG 膀胱灌注，副作用与断供没人问；或者刚做完根治术带着造口回家，不知道怎么换底盘、能不能洗澡游泳、什么时候算发烧要急诊；下次门诊想带一份说得清的材料

核心流程：
1. 把病理、膀胱镜、尿细胞学、影像与化验原文抄录/导入，标注哪些还没核对
2. 在分野页确认自己在 NMIBC 保膀胱线还是 MIBC 根治线，看懂 Ta/T1/Tis、两套分级与「未见肌层」意味着什么，知道哪些要问医生
3. 在手术页整理历次 TURBT（是否完全切除、是否二次电切）或根治术与改道方式；在灌注页记录 BCG/化疗灌注的周期、憋尿、副作用与中断原因
4. 在复查页安排膀胱镜节奏并记录每次的方式、疼痛与结果；在改道与造口页记录底盘、皮肤、渗漏与控尿或间歇导尿
5. 在指标页看肾功能、电解质与 B12 的长期趋势，在急症页确认血块尿潴留、BCG 全身感染、造口缺血、无尿腰痛的「立刻就医」边界
6. 生成一份复诊摘要，带去门诊；把想问的问题与临床试验线索一起收好

完成结果：患者能用自己的话说清自己在哪条线上、膀胱保不保得住要问什么、这次复查和灌注排到哪一步；造口或新膀胱的照护者能接手记录而不丢信息
